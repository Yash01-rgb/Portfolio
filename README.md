# Yash Gupta — Personal Portfolio

A personal portfolio website showcasing my background, technical skills, projects, and interests in Data Science and Artificial Intelligence.

🌐 **Live Website:** [portfolio25bcon1115.vercel.app](https://portfolio25bcon1115.vercel.app)

## ✨ Features

- **About Me:** Introduction, learning journey, and career goals.
- **Skills Section:** Highlights my current programming and web development skills.
- **Project Showcase:** Browse projects and search by title, description, or technology.
- **Light/Dark Mode:** Switch themes, with the selected preference saved in the browser.
- **Live Weather:** Enter a city to view current temperature, weather conditions, humidity, and wind speed.
- **AI Portfolio Assistant:** Ask questions about my portfolio, skills, and projects.
- **Responsive Design:** Layout adapts to different screen sizes.

## 🛠️ Technologies Used

- **HTML5** — page structure
- **CSS3** — styling, layout, themes, and responsive design
- **JavaScript** — interactive features and API requests
- **Open-Meteo API** — geocoding and current weather data
- **Vercel** — deployment

## 🚀 Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/Yash01-rgb/Portfolio.git
   ```

2. **Open the project folder**
   ```bash
   cd Portfolio
   ```

3. **Run the website**

   Open `index.html` in your browser, or use a local development server such as the Live Server extension in VS Code.

   Keep the referenced files and folders in their expected locations, including `style.css`, `script.js`, `chatbot.css`, `chatbot.js`, `config.js`, and the `images` folder.
